Validated ASPA objects from the RPKI, as seen by the Routinator validator at rpki.ping6.it (opens in a new tab).

An ASPA (Autonomous System Provider Authorization) is a signed RPKI object in which a customer AS lists the ASes allowed to act as its upstream providers. Routers use these lists to detect route leaks and some forged AS paths. A provider set of AS0 means the AS declares it has no upstream providers.
